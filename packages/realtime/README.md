# @arkyc/realtime

Server-side realtime event broadcasting for
[Arkyc](https://github.com/arkstack-hq/arkyc) — an open-source, multi-tenant
identity-verification platform. Provider-abstracted (soketi / Pusher-compatible
or Firebase) behind a stable contract, so session and review updates reach
dashboards live. Used internally by the Arkyc API; published for self-hosting.

## Install

```bash
npm install @arkyc/realtime
```

Docs: <https://docs.arkyc.toneflix.net>
