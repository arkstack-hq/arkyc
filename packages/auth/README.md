# @arkyc/auth

Authentication, token, and API-key helpers for
[Arkyc](https://github.com/arkstack-hq/arkyc) — an open-source, multi-tenant
identity-verification platform. Used internally by the Arkyc API; published for
self-hosting and extension.

## Install

```bash
npm install @arkyc/auth
```

Docs: <https://docs.arkyc.toneflix.net>
