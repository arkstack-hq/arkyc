# @arkyc/webhooks

Webhook signing, verification, and payload building for
[Arkyc](https://github.com/arkstack-hq/arkyc) — an open-source, multi-tenant
identity-verification platform. HMAC-SHA256 signatures with a timestamp, verified
in one call. (For app integrations, `@arkyc/sdk` re-exports `webhooks.verify`.)

## Install

```bash
npm install @arkyc/webhooks
```

Docs: <https://docs.arkyc.toneflix.net/integrations/webhooks>
