# @arkyc/permissions

Role-based access control (RBAC) resolution and enforcement for
[Arkyc](https://github.com/arkstack-hq/arkyc) — an open-source, multi-tenant
identity-verification platform. Resolves a member's effective permissions within
an organization and gates actions accordingly. Used internally by the Arkyc API;
published for self-hosting and extension.

## Install

```bash
npm install @arkyc/permissions
```

Docs: <https://docs.arkyc.toneflix.net/guide/rbac>
